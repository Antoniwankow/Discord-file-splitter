⚙️ Настройки

Тема интерфейса:

🔧 Разбиватель + Сборщик для Discord

⚠️ Перед использованием обязательно прочитайте важное предупреждение внизу страницы

1. Разбить большой файл

Рекомендуется 8–9 МБ для Discord (макс. 10 МБ для обычных пользователей)
🔸 Все части получат расширение .part (не исходное)

2. Собрать файл из частей

⚠️ Работает даже с одним файлом — это позволяет обойти сжатие Discord для небольших файлов.

⚠️ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ

Не разделяйте разделённые файлы повторно!

Части имеют расширение .part и зашифрованы. Их нельзя разбивать заново этим же инструментом.

❌ Неправильно:
  • Получатель скачивает одну часть (video.mp4_part001.part)
  • Разбивает её повторно
  • Итоговый файл после сборки будет испорчен
✅ Правильно:
  • Разбейте исходный файл (или зашифруйте один файл для обхода сжатия)
  • Отправьте ВСЕ части получателю
  • Получатель собирает их → получает исходный файл

⚠️ Причина: части зашифрованы. Двойное шифрование = потеря данных.
