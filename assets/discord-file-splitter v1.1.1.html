🔧 Разбиватель + Сборщик для Discord

⚠️ Перед использованием обязательно прочитайте важное предупреждение внизу страницы

1. Разбить большой файл

Рекомендуется 8–9 МБ для Discord (макс. 10 МБ для обычных пользователей)

2. Собрать файл из частей

⚠️ Убедитесь, что выбраны все части и порядок соблюдён (файлы сортируются автоматически по номеру)

⚠️ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ

Не разделяйте разделённые файлы повторно!

После того, как вы разбили файл на части (например, file_part001.dat, file_part002.dat и т.д.), эти части нельзя разбивать заново.

❌ Неправильно:
  • Отправитель разбивает исходный файл на части
  • Получатель скачивает одну часть (например, file_part001.dat)
  • Получатель разбивает file_part001.dat ещё раз этим же инструментом
  • При сборке файл будет повреждён и нечитаем
✅ Правильно:
  • Разделите исходный файл на части
  • Отправьте ВСЕ части получателю
  • Получатель собирает их обратно в исходный файл
  • Если нужно снова разбить — разбивайте уже собранный исходный файл, а не его части

⚠️ Результат повторного разбиения частей: потеря данных, невозможность восстановления файла при сборке.

Почему так происходит: при первом разбиении части шифруются. Если разбить зашифрованную часть повторно, она будет зашифрована дважды, и при сборке расшифруется только один раз, оставшись повреждённой.
